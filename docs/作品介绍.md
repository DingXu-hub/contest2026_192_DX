## 二、作品概述

一块**从零自研**的 openvela 智能手表固件：六页腕上 UI（表盘 / 跑步 / 轨迹 / 指南针 / 统计 / 设置），
以物理按键导航、触摸仅做页面内操作；在此之上实现了一个**运行在设备上的 AI Agent**，
满足 AI 硬件赛道"**主动 + 执行**"的核心要求。

三大亮点：

1. **设备侧 AI Agent（主动 + 执行）**
   - 执行：Agent 工具直接调用设备能力（开始/结束跑步、状态上报、设置提醒）
   - 主动：倒计时到点主动提醒；设备空闲 3 分钟主动请求 LLM 生成教练提示并弹屏
   - 渠道：串口 CLI（ASCII 行协议）；LLM 网络出口由 PC 侧脚本中继（如实说明，见第八节）
2. **自研多传感器融合与指南针**
   - 9 轴姿态：xioTechnologies/Fusion AHRS（NED）+ 自研磁力计驱动（20-bit 解包、
     每次测量自动 SET/RESET 去磁、饱和样本丢弃、弱场门控 + 陀螺降级 + 开机锚定）
   - 校准：15 秒图 8 字/翻滚校准（倒计时 + X/Y/Z 实时覆盖提示，覆盖不足自动拒绝）；
     程序内后台自动校准（3D 覆盖门控的球心拟合）；支持磁偏角（真北）设定
3. **无 GNSS 的航迹推算与自研渲染**
   - 重力投影偏航率积分 + 静止零偏再校准的航位推算，实时轨迹渲染、平移/缩放/海拔剖面

## 四、关键功能说明

### 4.1 AI Agent（主动 + 执行）

| 能力 | 说明 |
|---|---|
| 工具（执行） | `!start` 开始跑步（调用 run_engine）、`!stop` 结束并保存、`!status` 状态与传感器上报、`!timer N` 设置提醒、`!tip` 跑步建议、`!help` |
| 主动引擎 | ① 提醒到点主动弹出并上报 `@AI timer-due`；② 空闲 3 分钟主动请求 LLM 生成教练提示 |
| 交互渠道 | `/dev/console` ASCII 行协议（CLI 渠道，官方允许的渠道之一） |
| LLM 通路 | 设备发 `@LLMREQ <id> <prompt>` → PC 中继调 DeepSeek → 回 `@LLMRESP` → 屏幕通知卡片 |
| 呈现 | 表盘/任意页弹出通知卡片（8 秒，避让圆角与四角） |

### 4.2 指南针与传感器融合

- **融合**：xioTechnologies/Fusion AHRS（NED），加速度计取反喂入（本板物理平放 az≈-9.8）；
  静止时磁力计参与校正、剧烈运动时自动切换纯陀螺积累，内置加速度/磁场拒绝机制。
- **磁力计驱动**：标准 MMC5603NJ 寄存器映射（20-bit 数据、SET/RESET 脉冲）、
  每次测量启用 AUTO_SR 自动去磁、读取 STATUS 饱和位并丢弃异常样本。
- **磁场门控**：场强异常（过弱/过强）自动降级纯陀螺并在界面标注 `GYRO`，
  回到正常场强自动恢复；开机 2.5 秒强制用磁锚定，避免"开机即无航向"。
- **校准**：手动 15 秒（实时覆盖提示 + 失败拒绝）；后台自动校准（球心最小二乘 + 3D 覆盖门控 + 平滑应用）。
- **真北**：设置页可设磁偏角（-20…+20°），作用于航向显示与跑步起始方位。

### 4.3 跑步与航迹

- 步数/步频/配速（含平均配速）、距离；5 km 目标进度条。
- 航位推算：重力轴投影偏航率积分、静止零偏再校准、航迹环缓冲。
- 轨迹页（地图）：实时轨迹/GPX 路线预览/结束后回顾；拖动平移、双指缩放、长按海拔剖面。
- 统计页：累计次数/里程/时间 + 近期记录列表（KV 存储）。

### 4.4 交互与视觉

- 按键导航（KEY1 上一页 / KEY2 下一页），页面跳转仅由按键完成；触摸只做页面内操作。
- 全部动作使用**中轴大按钮**；无长按、无四角控件；屏幕圆角安全区（半径≈56 px）内不放置内容。
- 辅助文字统一 2×（10×14 px）以保证腕上可读性；极简深色主题。

## 六、技术难点与解决（均为真机验证）

| 难点 | 结论与解决 |
|---|---|
| 触摸屏多点驱动与板级适配 | 自研 FT6146 驱动补丁（多点上报）并接入 NuttX input 子系统 |
| 渲染掉帧（串口调试残留） | 移除每 5 秒导出帧缓冲的调试代码，改为按需重绘 + 脏标记，稳定 33 fps |
| 磁力计受板载干扰 | 硬磁/软磁校准 + 轴重映射（实验确定 `(-mx, +my, -mz)`）+ 弱场门控与陀螺降级 |
| 融合航向跳变 | 磁力计被丢弃时若处于启动期会被"归零"→ 增加 `headingAnchored` 标记，仅在从未用磁锚定时才归零 |
| 指南针/融合卡死（NaN） | 应用 Fusion 官方 `Residual()` 修复（传感器与参考恰好反向时返回零向量） |
| NuttX SLIP 发送恒失败 | 定位为 `IFF_RUNNING(0x04)` 缺失 → 应用侧调用 `netdev_carrier_on()` 修复 |
| 串口"收不到主机数据" | 实测收方向仅在 `/dev/console` 上可用（`/dev/ttyS0` 读不到），改用 `/dev/console` |
| 调试日志"消失" | 定位为 `ninfo/nerr` 受 `CONFIG_DEBUG_NET_INFO/ERROR` 控制，开启后可见 |
| 控制台与协议争用 | 将 NSH 控制台重定向至 `/dev/null`，应用再 `dup2` 回真实控制台，保证协议独占输入 |

## 七、测试与验证方式

- **真机**：黄山派 Pi（SF32LB52），编译产物直接烧录至应用区 `0x12010000` 运行。
- **串口日志**：启动标志（`[Mag] factory cal ...`、`[Sensor] LSM6DS3 IMU ready`、
  `[Fuse]` 2 Hz 融合诊断、`drp=` 磁场门控状态）与异常检查（无 hardfault/panic）。
- **界面**：板载一次性帧导出 + OCR 复核（确认无重叠/无越界、圆角安全区内无内容）。
- **AI 闭环**：终端输入 `!status` / `!start` / `?问题` / `!timer 1`，
  记录到"设备主动发起 → 云端返回 → 设备上屏"的完整日志（见 `docs/AI-AGENT.md`）。

## 八、已知限制（如实说明）

1. **板子不直接联网**：黄山派仅一个 Type-C 口（CH340 串口，SoC 的 USB D+/D- 未引出），板级无 WiFi；
   SLIP/PPP 直连主机的实现保留在 `src/net_link.c`、`src/ppp_link.c`，但受虚拟化 USB 直通稳定性影响
   未能端到端稳定联通。因此 **LLM 网络出口由 PC 侧脚本中继**；Agent、工具、主动逻辑均在设备上运行。
2. **无 GNSS**：轨迹为 IMU 航位推算，精度为相对轨迹级，非米级定位。
3. **无 RTC**：表盘时间为演示时钟（启动时设定基准），重启后回到基准值。
4. **无心率传感器**：健康相关建议仅基于运动/姿态数据。
5. 指南针在强磁场环境（贴近金属、大电流）会按设计降级为纯陀螺并在界面标注。

## 九、构建与运行（复现步骤）

```bash
# 1) 拉取工程（组委会命令）
repo init -u https://github.com/open-vela/contest2026_192_DX \
  -b dev-ai-contest-2026 -m contest2026_192_DX.xml
repo sync -c -j8

# 2) 配置与编译（黄山派 Pi）
export PATH=/home/openvela/prebuilts/cmake/linux-x86_64/bin:\
/home/openvela/prebuilts/build-tools/linux-x86_64/bin:\
/home/openvela/prebuilts/gcc/linux-x86_64/arm-none-eabi/bin:$PATH
cmake -B cmake_out/lckfb_huangshan_pi -S nuttx -GNinja \
  -DBOARD_CONFIG=../vendor/sifli/boards/sf32lb52/lckfb_huangshan_pi/configs/nsh
cmake --build cmake_out/lckfb_huangshan_pi --target final_nuttx
arm-none-eabi-objcopy -O binary cmake_out/lckfb_huangshan_pi/final_nuttx nuttx.bin

# 3) 烧录（串口）
sftool -c SF32LB52 -p <串口> -b 1000000 \
  write_flash nuttx.bin@0x12010000

# 4) 运行 AI Agent 演示（PC 侧，Windows/Linux 均可）
py -3 tools/llm_relay.py auto <DEEPSEEK_API_KEY>
#   然后输入： !status / !start / !timer 2 / ?<问题> / !help
```
