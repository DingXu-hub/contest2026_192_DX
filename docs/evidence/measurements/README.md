## 2. 磁力计校准（本项目的核心硬件问题）

测量方式：`APP_DIAG_VERBOSE=1` 构建，串口抓 `[MagS]`/`[Fuse]` 行；
翻滚采样原始 20bit 计数（0.5 s 一条），PC 端做最小二乘球面拟合。

| 指标 | 修复前 | 修复后 | 佐证文件 |
|---|---|---|---|
| 磁场总强度 \|B\|（同一姿势） | 4.5–83.4 µT（σ=20.0） | **35–56 µT**（σ=0.17 静止时） | `measurements/mag-tilt-109samples.json`、`mag-tilt-after-fix.json` |
| Fusion 磁误差 `em` | **90°**（长期） | **0–1°** | 串口 `[Fuse] ... em=` 日志 |
| 静止 yaw | 自行漂移 0°→175° | 稳定 | 串口 `[Fuse] yaw=` 日志 |
| 拟合球心/半径 | 旧值 (−3048,3101,−9498) | **(−4169,+1447,−5135) counts，半径 47.5 µT** | 拟合脚本输出（半径=当地地磁总场，31°N） |
| 桌面磁异常 | — | **184 µT（地磁 3.7 倍）** | 串口 `[MagS]` 日志 |

结论：`|B|` 是与朝向无关的标量，修复后在不同朝向下稳定在 35–56 µT，且拟合半径等于当地地磁总场——这是校准正确的物理自证。

### 2.1 两种球面拟合的对照（为什么两个球心不一致，以及采信哪一个）

2026-09-15 定版的代数拟合球心（已烘入固件）与 `tools/fit_mag_sphere.py`（Kasa + LM）对归档 JSON 重跑的结果不一致。逐条复核结论如下：

| 拟合 | 球心 (counts) | 半径 | 几何 RMS | 项目 8% RMS 门 |
|---|---|---|---|---|
| 文档/固件定版（2026-09-15 代数最小二乘，原始 capture `photos/mag_tilt.json`，**未归档**） | **(−4169, +1447, −5135)** | **47.5 µT** | — | — |
| 归档 JSON 重跑·纯 Kasa（`fit_algebraic`） | (−3767, +1476, −3985) | 44.3 µT | 4.65 µT（10.6%） | FAIL |
| 归档 JSON 重跑·Kasa+LM（`tools/fit_mag_sphere.py`，退出码 1） | (−3783, +1521, −3912) | 44.0 µT | 4.63 µT（10.5%） | **FAIL** |

不一致的具体原因（均已实测复核）：

1. **不是目标函数之争**：在同一归档数据上，代数（Kasa）与几何（LM 精化）两种目标函数的结果只差 16/45/73 counts（44.30 vs 44.01 µT）——目标函数差异解释不了 47.5 vs 44.0 µT 的间距。
2. **代数法在该数据上数值不稳**：样本距原点 4000–9000 counts，Kasa 正规方程混叠 ~10² 与 ~10⁹ 量级，条件数 ≈1.3×10⁸（质心化后仍 ≈2×10⁷）。两种数学上等价的正规方程写法，解相差 400–560 counts（未质心化时 >2000 counts）；其中一种写法落在 x=−4164，与定版 x=−4169 仅差 5 counts——即"代数拟合"的解随实现方式显著漂移。几何（LM）目标函数的雅可比是单位方向余弦，条件良好，从任意初值（含定版球心）出发都收敛到同一点。
3. **部分弧段覆盖**：109 个样本在八象限中每格仅 3–32 个（方向余弦平均合成长度 0.23），叠加各轴 ±7–13% 的软铁各向异性（半跨 6803/7144/7714 counts），球心沿弱覆盖方向（主要是 z）可滑动数百 counts。
4. **噪声与环境**：归档数据 RMS 4.63 µT = 半径的 10.5%，**未通过项目自设的 ≤8% 验收门**（`fit_mag_sphere.py` 退出码 1）；且该 capture 摄于修复前、工作台 184 µT 磁异常（地磁 3.7 倍）区域附近（见 `docs/指南针病因分析-2026-09-15.md` §4.2），按既定标准属"应拒绝的有偏拟合"。
5. **可复现性缺口**：定版所用原始 capture（`photos/mag_tilt.json`）未归档入仓；归档的 `mag-tilt-109samples.json` 在以上任何一种一致拟合下都复现不出 (−4169, +1447, −5135)，二者并非同一份数据。

**采信结论：固件继续烘入定版值 (−4169, +1447, −5135) + 软铁 scale (1.000/1.069/0.939)，不改为重跑值 (−3783, +1521, −3912)。** 依据是闭环真机验证而非单次离线拟合：烘入后 Fusion 磁误差 `em` 由 90° 降至 0–1°、静止 yaw 不再漂移、|B| 与朝向无关（35–56 µT，静止 σ=0.17 µT）、且定版半径 47.5 µT 等于 31°N 当地地磁总场（IGRF ≈ 47–48 µT）。对归档 JSON 的重跑拟合未过 8% RMS 门，按项目既定验收标准应予拒绝，不构成改值依据。

**若将来重新定标**：离桌面 ≥1 m 重新翻滚采样 → 几何（LM）目标（Kasa 仅作初值且须质心化）→ 通过 8% RMS 与 25–65 µT 半径双门 → 真机验证 `em` 与 |B| 朝向不变性后再烘入，并将原始 capture 一并归档。

## 3. 串口链路（联网功能）

测量方式：`tools/link_test.py`（帧协议自测）与 `tools/gateway.py`（网关）。

| 指标 | 数值 | 佐证文件 |
|---|---|---|
| 帧 ACK 成功率 | 6/6（含 WHOAMI/PING/文本命令） | `serial-logs/gateway-ping-link.log` |
| PING→PONG 往返 | **52–79 ms** | `serial-logs/gateway-ping-link.log` |
| 时间同步 | 与 PC 同秒：`clock set to 2026-09-15 17:17:26 (tz=UTC-8:00)` | `serial-logs/gateway-time-sync-http.log` |
| 真实互联网访问 | `!http https://api.github.com/zen` → **HTTP 200** + 正文 | `serial-logs/gateway-time-sync-http.log` |
| LLM 通道 | `?question` → `@LLMREQ` → DeepSeek → 回传 | 同上（本轮未带 key 时返回 `(no api key)`） |
| 控制台 RX 特性 | 63 字节突发仅 2–19 字符到达；**逐字节 1 ms 间隔 63/63** | 实验记录（`tools/link_test.py`、见 `docs/联网功能与串口根因-2026-09-15.md`） |

> 说明：PC→手表方向因 CH340/控制台 RX"等效 1 字节深"，网关采用**逐字节节流写**（1.2 ms/字节 ≈ 830 B/s），
> 上层再叠加 CRC16 + ACK + 重传，因此**应用层不会丢命令**；设备→PC 方向不受限（实测曾跑通 526 KB 帧传输）。
