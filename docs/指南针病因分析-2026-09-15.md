# 指南针（MMC5603NJ）病因彻查报告

日期：2026-09-15　对象：`huangshan_running` 指南针后端（磁力计驱动 + Fusion AHRS 融合）
方法：**逐行比对官方上游源码 + 数据手册 + 设备实测取证**

---

## 0. 一句话结论

**病因不在驱动协议，也不在 Fusion 算法，而在"编译进固件的硬铁校准值"**：Z 轴偏移是按"平放时让 mz≈0（把地磁垂直分量吸收掉）"拍出来的，物理上错误。它导致磁场总强度 \|B\| 随朝向在 **4.5–83.4 µT** 之间乱跳（地磁恒为约 47.5 µT），Fusion 内部磁误差 `em` 恒为 **90°**，静止时航向自己从 0° 走到 175°。
另外查出一个**环境主因**：工作台区域存在 **184 µT**（地磁 3.7 倍）的强磁异常，这正是历史上"在桌面上怎么标都不对"的根源。

## 2. 寄存器层核对（我们 vs Adafruit vs 手册）

| 项目 | 我们的实现 | 官方/手册 | 判定 |
|---|---|---|---|
| 20-bit 解包 | `(b0<<12)\|(b1<<4)\|(b6>>4)` 后 `-1<<19` | Adafruit 完全相同 | ✅ 一致 |
| 灵敏度 | `0.00625 µT/LSB` | Adafruit 注释 + 手册（±30 G / 20 bit） | ✅ 一致 |
| one-shot 触发 | `CTRL0 = TM_M \| Auto_SR_en = 0x21` | 手册：Auto_SR_en"**on-demand 与连续模式都适用，推荐置 1**"，I2C 流程示例即 `00100001` | ✅ **我们更贴合手册**（Adafruit 只写 `0x01`） |
| 复位与消磁 | `CTRL1=0x80` → 20 ms → `CTRL0=0x08`(SET) → `CTRL0=0x10`(RESET) | Adafruit `reset()` 完全相同；手册 SW_RST 上电时间 20 ms | ✅ 一致 |
| CMM 位 | 初始化曾写 `CTRL0=0x80`(Cmm_freq_en) | 该位只用于连续模式计算测量周期；Adafruit 仅在连续模式写 | ⚠️ 多余，**已移除** |
| **STATUS1 bit5** | 当作"磁场饱和"→ **丢弃整个样本** | 手册 bit5 = `Sat_sensor`：**自检信号指示位，"自检通过后保持低"**；真正的饱和检测要靠 CTRL1 的 `St_enp/St_enm` 自检线圈 | ❌ **错**（实测 `st=0x51`，bit5=0 故未触发，属潜在 bug，**已修正为不丢样本**） |
| 状态位 bit6/bit4 | `0x40` 数据就绪 / `0x10` OTP 完成 | 手册 bit6 `Meas_m_done`、bit4 `OTP_read_done` | ✅ 一致 |
| CTRL0 位表 | `0x01/0x02/0x04/0x08/0x10/0x20/0x80` | 手册 bit0..7：TM_M / TM_T / Start_MDT(厂用) / Do_Set / Do_Reset / **Auto_SR_en** / Auto_st_en / Cmm_freq_en | ✅ 一致 |

**结论：寄存器层没有协议错误。** 唯一实质性错误是 STATUS bit5 的语义（潜在，未触发）。

## 3. 融合层核对（Fusion v1.3.3）

| 项目 | 我们的用法 | 判定 |
|---|---|---|
| 单位 | gyro °/s、accel **g**（`/G_MS2`）、mag µT | ✅ 与 Fusion 约定一致 |
| 约定 | `FusionConventionNed` + 机体 X=12点/Y=3点/Z=屏幕内 | ✅ |
| 采样周期 | 每帧用真实 dt 调 `FusionAhrsSetSamplePeriod()` | ✅ **比上游 refactor 更适合变采样率**（见下） |
| 拒绝/恢复 | `accelRejection=15°`、`magRejection=15°`、`rejectionTimeout=5 s`；磁恢复另设 20 s | ✅ 语义合法 |
| 版本 | 我们的基线 `e2e9cc0` 缺 4 个上游提交 | ⚠️ 见 §3.1 |

### 3.1 版本混用（已查清，明确"不要盲抄"）
- `FusionMath.h` 实测更接近 **v1.3.2**（差 2 行），而 `FusionAhrs.*` 是 `e2e9cc0`——**混版**。
- 缺失的上游提交：`0e5da68`(多余乘法重构)、`998a3e5`(**Fix startup**)、`26a3a00`(默认设置 90→0)、`f84a8d8`(NaN 防护，**我们已手工补上**)。
- ⚠️ **关键**：上游把 `startupGainRate` 从 `Restart()` 移到 `SetSettings()`，其前提是"采样周期只设置一次"。我们是**每帧用真实 dt** 更新 samplePeriod，旧写法的 `startupGain -= rate * samplePeriod` 恰好对变 dt 正确；**直接照抄上游反而会引入 stale rate 的 bug**。
- 结论：保持 `e2e9cc0` + 手工 NaN 修复，并在代码注释中禁止无改造地升级该 refactor。

### 3.2 自有补丁评估
- `headingAnchored`（磁被门控时不清零航向）+ `magneticRecoveryTimeout`（磁恢复 20 s）逻辑自洽；
- 但原实现"**开机 2.5 s 内无条件强制喂磁**"会把一个**错误**的磁航向锚定并锁死 → 已改为**要求幅值物理合理**才允许锚定。

## 4. 病因链（全部有实测数字）

### 4.1 主因：Z 硬铁偏移是"拍"出来的错值
- 固件旧默认：`(-3048, +3101, -9498)` counts。平放实测 `mz=+107 µT`、`|B|=112 µT`（地磁应约 47.5 µT）。
- 用 **109 样本 3D 翻滚**做最小二乘球面拟合：**球心 = (-4169, +1447, -5135) counts，半径 = 47.5 µT**——**半径恰好等于当地地磁总场**（黄山 ~31°N，IGRF ≈ 47–48 µT），这是物理自证。
- 与固件旧值之差：X **+7.0 µT**、Y **+10.3 µT**、Z **−27.3 µT**。
- 后果链：\|B\| 随朝向 4.5…83.4 µT（标准差 20）→ `em` 恒 90° → 静止时 yaw 由磁反馈慢慢拽走 0→39→98→…→175° → 倾斜时倾斜补偿彻底失效（代码注释里"41° 倾斜时 −44° 误差"是同一病根）。

### 4.2 环境主因：工作台有 184 µT 强磁异常
同一块表、同一分钟：
```
桌面上     |B| = 184 µT   ok=0   （被新门限正确拒绝）
举到空中   |B| = 56 37 49 52 47 47 51 43 35 42 41 42 …  → 35–56 µT ✓
```
→ 历史上在桌面上标定，等于把"3.7 倍地磁"当成地磁来解方程，必然得到诡异偏移。

### 4.3 次因：门限过松 / 状态位语义
- 驱动侧 `10–200 µT`、融合侧 `12/130/18 µT`：既能放行 112 µT 的坏数据，又会在有效样本上抖动 → 已改为物理窗口 **20/80 µT（28–65 清除）**。
- STATUS bit5 误解（§2）。

## 5. 已实施修复（已编译烧录并实测）

1. **烘入校准换成 LSQ 球心**：`OX/OY/OZ = -4169/+1447/-5135`，软铁 scale = `1.000/1.069/0.939`（各轴半跨度 6803/6368/7244 counts）。
2. **设备端标定改为最小二乘球面拟合**，并加三重验收：
   - 覆盖度：每轴跨度 ≥ 2000 counts 且样本数 ≥ 80；
   - **物理自检：拟合半径必须在 25–65 µT**（地磁全球范围）；
   - **新增拟合质量门限：RMS 半径偏差 ≤ 8%**（用来拒绝"翻滚时靠近金属"的有偏解——实测那次有偏拟合半径 41.3 µT，与真值 47.5 µT 差 13%）。
3. **STATUS bit5 不再丢样本**（改为自检标志记录，5 s 限频）。
4. **幅值门限物理化**（20/80，清除 28–65），开机锚定期同样要求幅值合理。
5. 初始化去掉 CMM 位写入，与 Adafruit/手册一致；清理死变量。
6. 新增 `[MagS]` 诊断行（`APP_DIAG_VERBOSE` 门控）：输出 STATUS 字节、原始计数、µT 向量、\|B\|、健康标志。

## 7. 遗留与建议

1. **演示/标定必须离开桌面至少 1 m**（桌面 184 µT）。建议写入演示脚本与交接文档的操作注意。
2. **锚定期**：上电 2.5 s 的磁锚定现已带幅值门限；更进一步可绑定"磁误差 `em` 收敛"作为二次条件。
3. **Fusion 版本**：保持 `e2e9cc0` + 手工 NaN 修复；若将来升级到 v1.3.3+，必须同时改造 dt 处理（见 §3.1）。
4. **软铁**：本次只有 ±7% 的各轴比例差异，已烘入；若追求更高精度，可做完整椭球拟合（含轴间耦合，本次实测相关系数约 −0.2，属覆盖不足而非真实耦合）。
5. **STATUS bit5**：若将来要做真正的饱和自检，需按手册驱动 CTRL1 的 `St_enp/St_enm` 自检线圈并比较偏移。
